# Week 6

Module 1 — Getting Started with C++

This module introduces the basics of C++ syntax, data types, and console output. The assignment includes creating a simple “Hello Inventory System” program that uses escape sequences and displays data type sizes. It also walks through setting up a GitHub repository and uploading the first source file.

Module 3 — Input, Output, and Variables

This module focuses on collecting user input and performing basic arithmetic using variables. The program prompts the user for an item name, quantity, and cost, then calculates the total price. It demonstrates foundational input/output handling using cin and cout.

Module 4 — Debugging and Logic

This module covers debugging techniques and the use of conditional logic. Students build a simple menu using if statements and rewrite a broken program to correctly determine the largest of three numbers using nested conditionals. The goal is to differentiate syntax errors from logical errors and apply structured decision-making.

Module 5 — Functions and Loops

This module introduces modular program structure through functions and loop-driven menus. The assignment requires creating a reusable menu where each option calls a separate function. It reinforces how functions improve code organization and how loops enable continuous program interaction.

Module 6 — Strings and Classes

This module combines string handling, class design, and file I/O. The assignment involves building an Item class that saves item data to a text file and retrieves it for display. It serves as an introduction to object-oriented programming and persistent data storage.

Module 7 — Pointers and Memory

This module explores dynamic memory, structs, and binary search. Students create a dynamically allocated array of inventory items, populate it with sample data, and implement a binary search to look up items by ID. The exercise emphasizes memory management and efficient search techniques.

Module 8 — Bank Account Simulation

This module builds a practical class that manages a user’s account balance with deposits and purchases. All transactions are saved to a text file, simulating permanent financial records. The program demonstrates encapsulation, file writing, and real-world class behavior.

Module 9 — Inventory Management with Arrays

This module applies class usage and arrays to create a small inventory system. Students store multiple Item objects in an array, allow users to input data, display all items, and search for an item by name. It reinforces array traversal and object storage.

Module 10 — Inheritance and Method Overriding

This module introduces inheritance through a class hierarchy representing different user roles. Each derived class overrides an accessLevel() method to reflect role-specific permissions. It demonstrates polymorphism and how subclasses modify parent behavior.

Module 11 — Constructors and Destructors

This module explores object lifecycle management in C++. Students create a Product class with a constructor, destructor, and a method to print product details. It shows how initialization and cleanup occur automatically as objects are created and destroyed.

Module 12 — Working With External Data

This module introduces real-world data handling by reading and displaying records from a CSV dataset. The program loads at least 10 entries and extracts multiple fields from each row. It demonstrates file parsing, string manipulation, and structuring external data in C++.
