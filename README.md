# Week 7

Module 1 — Getting Started with C++

This module introduces basic C++ syntax, output formatting, escape characters, and data type sizes through a simple “Hello Inventory System” program. It also covers setting up your development environment and GitHub workflow.

Module 3 — Input/Output & Variables

This module focuses on user input and variable handling by creating a program that reads item details, performs a calculation, and outputs the total cost.

Module 4 — Debugging and Logic

This module teaches debugging, conditional logic, and if-statement structure by building a simple menu system and correcting faulty code that identifies the largest of three numbers.

Module 5 — Functions and Loops

This module introduces function creation and looping by designing a menu where each option triggers a separate function until the user chooses to exit.

Module 6 — Strings and Classes

This module covers class creation, string usage, and file I/O by building an Item class that can save data to a text file and read it back.

Module 7 — Pointers and Memory

This module teaches structs, dynamic memory allocation, and binary search by creating a large inventory list and searching for items by ID.

Module 8 — Bank Account Simulation

This module explores class design and file persistence by implementing a BankAccount class that manages purchases, deposits, and writes transaction history to a file.

Module 9 — Inventory Management with Arrays

This module reinforces class usage and array operations by building a small inventory system where the user enters items, views them, and searches by name.

Module 10 — Inheritance & Method Overriding

This module demonstrates inheritance and method overriding by creating a role-based user hierarchy where each class redefines its access level.

Module 11 — Constructors & Destructors

This module focuses on object lifecycle by creating a Product class with a constructor, destructor, and a method to display product details.
