# CIS-25


Module 1 introduces the basics of C++ by printing output to the console, using escape characters, and displaying data type sizes, while also practicing setting up a GitHub repository and branch for version control.

Module 3 focuses on user input and variables by collecting item information from the user and calculating a total cost using basic arithmetic and console input/output.

Module 4 teaches program logic and debugging by building a simple menu with conditional statements and correcting logical and syntax errors to determine the largest of three values.

Module 5 reinforces the use of functions and loops by creating a menu-driven program where each option calls a separate function to perform an action.

Module 6 applies strings, classes, and file input/output by creating an inventory item class and saving and loading item data from a text file.

Module 7 introduces pointers and dynamic memory allocation by creating a dynamically sized inventory array and using a binary search algorithm to locate items efficiently.

Module 8 demonstrates class design and file handling by simulating a bank account that records deposits and purchases while saving transaction history to a file.

Module 9 builds on arrays and classes by creating a small inventory management system that stores multiple items, displays them, and allows searching by name.

Module 10 explores inheritance and method overriding by modeling different user roles and demonstrating how derived classes customize behavior from a base class.

Module 11 focuses on constructors and destructors by tracking object creation and cleanup while displaying product details.

Module 12 applies file processing and real-world data handling by reading a CSV dataset, extracting multiple fields using a class, and displaying formatted data from an external source.
